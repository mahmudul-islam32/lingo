## User story

ticket implements each reference screen, so that I can find the right reference and owner
quickly.

ticket. The folder has `BRIEF.md`, `screen-1..8.png` and `screen-1..8.html`, but no
`README.md`. Token names are documented in ADR-014, so AC 2 is met.

   `BRIEF.md` and ADR-014.
3. It lists the accepted deviations from the design with their decision IDs (PD-067,
