# CON-001: Unit 1 content: 5 original lessons (en → es)
**Owner:** pm · **Priority:** P0 · **Depends on:** CTO-002 (course contracts and zod schemas) · **Milestone:** v0.2.0

Written by the pm **after** CTO-002 is merged, strictly following the schemas in
`/src/contracts`. Until then, devs use schema-valid test fixtures.

## User story
As a beginner, I want Unit 1 to teach everyday basics (greetings, introductions, food,
numbers, places) so that I can use them right away (US-CON-01, US-CON-03).

## Acceptance criteria
1. One course (English speakers learning Spanish) with one unit, "First Steps", stored in
   `/content/` at the path and file layout the cto defines.
2. The unit has exactly 5 lessons, in this order and with these themes:
   1. "Hello!" — greetings and goodbyes
   2. "Nice to Meet You" — names, "I am", "you are", where I'm from
   3. "At the Café" — food and drink, asking politely, numbers 1–3 (PD-013)
   4. "Count It" — numbers 1 to 10 (4–10 new, 1–3 reviewed), "how many"
   5. "Around Town" — places in a town, "where is"
3. Each lesson has 10 to 12 exercises with this mix: at least 3 multiple choice, at least
   3 translate (word bank) with at least 1 in each direction, exactly 1 match pairs with
   5 pairs, and at least 2 listen.
4. Each lesson introduces 5 to 8 new words or phrases, listed in the Vocabulary appendix
   below when the content is written. An exercise only uses words introduced in that
   lesson or an earlier one (plus distractor tiles, which must also be Unit 1 words).
5. Every translate and listen exercise lists all reasonable alternative answers (for
   example "Hi" and "Hello"; "I am Ana" and "I'm Ana"), so a valid answer is accepted
   (US-CON-03).
6. Each word bank has 2 to 4 distractor tiles, and no combination of tiles can form a
   valid answer that isn't in the accepted list (checked by the pm's review per exercise).
7. Spanish is neutral Latin American Spanish: `ustedes`, never `vosotros`, correct accents,
   `ñ`, `¿ ?` and `¡ !` (PD-002).
8. Every sentence, word choice, example name and lesson theme is original, written for
   Polyglow. Nothing is copied or adapted from any other language app, course, textbook or
   website. Example names are varied and invented (no celebrities, no brand names).
9. Every listen exercise has an audio reference in the format the contracts define.
   Placeholder audio is allowed until the TTS licence is decided (PRD Q7); missing files
   are handled by the LES-007 fallback (PD-007).
10. Each lesson has a tip line of at most 120 characters, if the contracts include a tip
    field (shown by LES-013 in v1.0.0).
11. Content is beginner-friendly and inclusive: no slang, no sensitive topics, and where
    Spanish has gendered forms (e.g. "Estoy cansado / cansada"), both are accepted or the
    sentence avoids the issue.
12. All content files pass the zod validation test (`npm run test`, PLT-007 criterion 1).
13. Exercise ids are unique across the course and stable (later edits keep ids so saved
    results stay valid).

## UX notes
- Prompts are short (at most 80 characters) so they fit at 375 px without scrolling.
- English instructions use the same wording everywhere: "Translate this sentence", "Tap
  what you hear", "Match the pairs", "Which one means '<word>'?".
- Lesson length target: under 5 minutes for a learner who makes 1–2 mistakes.

## Vocabulary appendix

| 1 | Hello! | hola (hello / hi), adiós (goodbye / bye), buenos días (good morning), buenas tardes (good afternoon), buenas noches (good evening / good night), ¿cómo estás? (how are you?), bien (well / fine / good), gracias (thank you / thanks) | 8 |

Notes:
- **Numbers 1–3 are taught in "At the Café"** (ordering one, two or three items), and
  "Count It" introduces 4–10 and reviews 1–3, so it still covers "numbers 1 to 10"
  (criterion 2) with 8 new items instead of 11 (PD-013).
- `un` / `uno` and `el` / `la` count as one entry each: the pair is taught together.
- English glosses list the accepted alternatives the translate and listen exercises must
  include (criterion 5), e.g. "Hi" / "Hello", "I'd like" / "I want".

## Technical notes
_(cto, 2026-11-07)_

**Owner agent:** pm · **Branch:** `docs/con-001-unit-1-content`

- **Contracts (`src/contracts/course.ts`):** `CourseSchema` for `content/courses/en-es/course.json` (`id: "en-es"`, `learningLanguage: "es"`, `knownLanguage: "en"`, `version: 1`, one unit `id: "unit-1"` with 5 `LessonSummary` entries in criterion 2's order) and `LessonSchema` for `content/courses/en-es/lessons/<lessonId>.json` (one file per lesson, file name = `id`). Ids are lowercase kebab-case slugs; use `u1-lN-<theme>` lesson ids and prefix exercise ids with the lesson (`u1-l1-ex01` …) so they are unique across the course (criterion 13; the schema only checks uniqueness inside a lesson).
- **Exercise shapes:** `multiple_choice` (`prompt`, 3–4 `options` with `id`/`text`, `correctOptionId`); `word_bank_translate` (`direction` `to_learning` = English prompt, Spanish tiles; `to_known` = reverse; `tiles` ≤ 16 incl. 2–4 distractors; `answers[0]` canonical, all alternatives listed); `match_pairs` (exactly 5 `pairs` with `id`, `learning`, `known`, no duplicate words on either side); `listen` (`audio.src`, optional `audio.slowSrc`, `tiles`, `answers[0]` = exact transcript). Every answer must be buildable from its tiles after `normalizeAnswerText` (the schema checks it).
- **UI copy is not content:** "Translate this sentence", "Tap what you hear", "Match the pairs" are rendered by the components. MC `prompt` is the full question ("Which one means 'water'?") in English with Spanish options.
- **Audio:** paths `/audio/es/<lesson>/<exercise-id>.mp3` (regex `AudioPathSchema`). Files are not required until `CONTENT_REQUIRE_AUDIO=1`; LES-007 falls back to speech synthesis.
- **Tip:** `tip` (schema max 200 chars; this ticket's 120-char limit is stricter and fine).
- **Speak:** none in this ticket (PD-006).
- **Testing:** `npm run test` runs `src/contracts/__tests__/content.test.ts` (schema per file, one file per manifest entry, matching `courseId`/`unitId`). Run `npx vitest run src/contracts/__tests__/content.test.ts` locally before pushing. The cto reviews the CI result; the pm records the criteria 4–8 self-review in Review.
