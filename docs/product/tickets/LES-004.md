# LES-004: Multiple-choice exercise
**Owner:** dev-lessons · **Priority:** P0 · **Depends on:** CTO-002 (and the props interface in LES-002 Technical notes) · **Milestone:** v0.2.0

## User story
As a learner, I want to answer multiple-choice questions so that I can recognise Spanish
words and phrases (US-LES-03).

## Acceptance criteria
1. Shows the exercise prompt as a heading and the 3 or 4 text options from the content.
2. Options are shuffled each time the exercise is shown (a re-queued exercise may appear
   in a different order).
3. Tapping or clicking an option selects it; selecting another moves the selection. Only
   one option is selected at a time.
4. Options form a `role="radiogroup"` labelled by the prompt. Arrow keys move between
   options and select; Tab leaves the group.
5. Number keys 1–4 select the matching option when focus is inside the exercise.
6. The selected option shows a check-style marker and a stronger border, not only a
   colour change.
7. The component reports "answer ready" as soon as an option is selected, and reports the
   selected option id as the answer.
8. When disabled (after "Check"), options can't be changed; the correct option is marked
   with a check icon, and a wrongly selected option is marked with a cross icon.
9. Spanish text in the prompt or options is wrapped in `lang="es"`.
10. At 375 px: options are full width, at least 48 px tall, and long text wraps instead
    of being cut off.
11. Unit tests cover: render, mouse selection, keyboard selection (arrows and 1–4),
    "answer ready" callback, disabled state markers.

## Out of scope
- Image options (Phase 2)
- Audio on options (Phase 2)

## UX notes
- Prompt example style (content comes from CON-001): "Which one means 'water'?"
- Option cards: white card, indigo text, number hint (1–4) on the left on wider screens.
- **Loading/empty/error:** handled by the player (LES-002). If the content has fewer than
  2 options, the component reports "skipped" so the lesson can continue (and the content
  test in CON-001 must catch it).
- **Success:** markers as in criterion 8.

## Technical notes
_(cto, 2026-11-07)_

**Owner agent:** dev-lessons · **Branch:** `feature/les-004-multiple-choice`

- **Contracts:** `ExerciseComponentProps<"multiple_choice">` (LES-002 notes), `MultipleChoiceExercise` (`prompt`, `options: { id, text }[]`, `correctOptionId`, optional `audio`), answer `AnswerInputOfType<"multiple_choice">` = `{ type: "multiple_choice", optionId }`, `CONTENT_RULES.multipleChoiceMinOptions`.
- **Files:** `src/features/lessons/exercises/multiple-choice/MultipleChoiceExercise.tsx` (+ test), shared pure helper `src/features/lessons/exercises/shuffle.ts` (`shuffle<T>(items, random = Math.random): T[]`, Fisher–Yates, unit-tested; shared with LES-005/006, whoever lands first creates it). Register in `exercises/registry.ts`.
- **Behaviour:** shuffle once per mount (`useState(() => shuffle(options))`; the player remounts on each presentation via `key`). `role="radiogroup"` with `aria-labelledby={headingId}`; options `role="radio"` + `aria-checked`, roving `tabIndex` (selected or first = 0, others −1). Arrow keys move+select (wrap around), digits 1–4 select (`preventDefault`). On change call `onAnswerChange({ type: "multiple_choice", optionId })`.
- **Review state:** when `review` is set, mark `exercise.correctOptionId` with `CheckIcon` (+ VisuallyHidden "correct answer") and the selected wrong option with `CrossIcon`; `disabled` → `aria-disabled` on the group and ignore input.
- **Languages:** options are in the learning language unless the prompt asks for the known language; content has no per-option language, so wrap options with `lang={learningLanguage}` and the prompt with `lang={knownLanguage}` (CON-001 writes MC prompts in English and options in Spanish; if a lesson needs the reverse, raise a contract request for a `direction` field).
- **Edge case:** fewer than `CONTENT_RULES.multipleChoiceMinOptions` options or `correctOptionId` not among them (schema prevents this) → `onSkip("invalid_content")` in an effect.
- **UI (CTO-004):** option rows as `Card`-styled `button`s (`min-h-12 w-full`), `cn()`; selected = `border-primary` + check marker, not colour only.
- **Tests:** RTL: render with a fixed `random` (inject via an optional `random` prop defaulting to `Math.random`, not part of the shared props), click select, arrows, digits, `onAnswerChange` calls, disabled review markers, `lang` attributes.
