# LES-004: Multiple-choice exercise
**Owner:** dev-lessons · **Priority:** P0 · **Depends on:** CTO-002 (and the props interface in LES-002 Technical notes) · **Milestone:** v0.2.0

## User story
As a learner, I want to answer multiple-choice questions so that I can recognise Spanish
words and phrases (US-LES-03).

## Acceptance criteria
1. Shows the exercise prompt as a heading and the 3 or 4 text options from the content.
2. Options are shuffled each time the exercise is shown (a re-queued exercise may appear
   in a different order).
3. Tapping or clicking an option selects it; selecting another moves the selection. Only
   one option is selected at a time.
4. Options form a `role="radiogroup"` labelled by the prompt. Arrow keys move between
   options and select; Tab leaves the group.
5. Number keys 1–4 select the matching option when focus is inside the exercise.
6. The selected option shows a check-style marker and a stronger border, not only a
   colour change.
7. The component reports "answer ready" as soon as an option is selected, and reports the
   selected option id as the answer.
8. When disabled (after "Check"), options can't be changed; the correct option is marked
   with a check icon, and a wrongly selected option is marked with a cross icon.
9. Spanish text in the prompt or options is wrapped in `lang="es"`.
10. At 375 px: options are full width, at least 48 px tall, and long text wraps instead
    of being cut off.
11. Unit tests cover: render, mouse selection, keyboard selection (arrows and 1–4),
    "answer ready" callback, disabled state markers.

## Out of scope
- Image options (Phase 2)
- Audio on options (Phase 2)

## UX notes
- Prompt example style (content comes from CON-001): "Which one means 'water'?"
- Option cards: white card, indigo text, number hint (1–4) on the left on wider screens.
- **Loading/empty/error:** handled by the player (LES-002). If the content has fewer than
  2 options, the component reports "skipped" so the lesson can continue (and the content
  test in CON-001 must catch it).
- **Success:** markers as in criterion 8.
