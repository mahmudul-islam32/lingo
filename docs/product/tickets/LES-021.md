# LES-021: Redesign v2 for the lesson player, exercises, feedback and results
**Owner:** dev-lessons · **Priority:** P1 · **Depends on:** CTO-016 · **Milestone:** v0.5.3
Redesign · **Decisions:** PD-065, PD-066

## User story
As a learner, I want lesson screens with big, clear answer cards, obvious feedback and a
rewarding results screen, so that I can focus on the language and feel my progress after
each lesson.

## Acceptance criteria
References: `docs/design/v2/screen-3.png` (MC), `screen-4.png` (word bank), `screen-5.png`
(feedback, listen), `screen-6.png` (results), brief tokens. **No behaviour change; existing
tests keep passing** (scoring, re-queue, hearts, practice, XP and copy unchanged).

### Header (screens 3–5)
1. Close (X) button left (accessible name "Close lesson"), indigo ProgressBar in the middle,
   hearts with count at right; in practice the existing "Practice" badge stays visible.

### Exercises
2. **Multiple choice (screen 3):** uppercase eyebrow (e.g. "NEW WORD" / existing exercise
   label), Bricolage prompt, options as a **2 × 2 grid of numbered OptionCards** (1–4; 1 column
   if an option text does not fit at 375 px); selected = indigo ring; number keys 1–4 select.
3. **Word bank (screen 4):** round indigo speaker button next to a prompt speech bubble, an
   answer line with placed tiles, and word-bank tiles as white 3D chips; placed tiles leave a
   grey placeholder.
4. **Listen (screen 5):** big indigo speaker button (at least 96 px) and a smaller "0.7×" slow
   button (accessible names "Play audio" / "Play slowly"); existing audio fallbacks unchanged.
5. **Match pairs:** two columns of 3D tile Cards; selected = indigo ring, matched = green
   tint + check, mismatch = red flash; same behaviour as today.
6. **Cloze:** sentence with the gap shown as an underlined slot; options as OptionCards.
7. **Check bar:** full-width primary Button at the bottom, grey with no 3D edge when disabled
   (screen 3).

### Feedback and states (screen 5)
8. **Incorrect:** red-tint bottom sheet, heading "Not quite …"-style existing copy with an
   icon, "CORRECT ANSWER" eyebrow and the answer, red 3D "Got it" button.
9. **Correct:** same sheet in green with a green 3D continue button.
10. The sheet is announced via `aria-live` (existing behaviour) and its button gets focus.
11. **Tip card** (LES-013) and **out-of-hearts** screen (PD-065 copy) restyled with Card,
    Lumi and primary Button; copy and actions unchanged.

### Results (screen 6)
12. Lumi (or the trophy illustration with Lumi) in a light indigo circle, "Lesson complete!"
    Bricolage heading and the existing subline.
13. Three StatTiles with coloured headers: **TOTAL XP** (gold), **TIME** (indigo, m:ss),
    **ACCURACY** (green, %), all from the real result.
14. Coral-tint streak banner with flame, "<n>-day streak!" and the existing line, shown only
    when the existing results screen shows the streak.
15. Indigo full-width "Continue" Button; no "Review my mistakes" link (not built).

### Quality
16. No serious or critical axe violations on each exercise type, both feedback sheets, tip
    card, out-of-hearts and results; all text meets AA (gold header text uses `#8A6200` or
    dark ink on gold, not white at body size).
17. At 375 × 667 every screen fits without horizontal scroll; the Check bar and sheets stay
    visible above the on-screen keyboard where there is a text input; tap targets at least
    48 px.
18. Keyboard only: every exercise, the sheet button, tip card, out-of-hearts and Continue
    work with Tab and Enter / Space (plus number keys for MC); focus ring visible.
19. RTL tests for the new layouts (2 × 2 grid with numbers, slow button present, sheet
    colours by result, three stat tiles) and the existing lesson e2e still passes at 375 px.
20. `npm run typecheck`, `lint`, `test`, `build` and existing e2e pass.

## Out of scope
- New exercise types or copy changes
- "Review my mistakes" (Phase 2 idea)
- Speak exercise behaviour (only restyled if it shares the components above)
- Path, Practice, Leagues (GAM-012); onboarding, nav, Profile (PLT-026)

## UX notes
- **Loading:** lesson skeleton (header + 4 card placeholders).
- **Error:** existing load error restyled (Card + "Try again" Button).
- **Success:** green sheet, then next exercise; results after the last one.
- Feedback colour is never the only signal: icon + heading text in each sheet.
