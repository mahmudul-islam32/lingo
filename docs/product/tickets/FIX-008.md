# FIX-008: Practice tab test uses a fixed clock
**Owner:** dev-gamification · **Priority:** P1 (blocked the v0.5.3 merge) · **Depends on:**
GAM-012 · **Milestone:** v0.5.3 Redesign · **Found in:** cto review of GAM-012

## User story
As a developer, I want the Practice tab tests to pass on any day, so that CI doesn't fail
because the hearts refill ran on the real clock.

## Problem
`PracticeScreen.test.tsx` built hearts at a fixed `NOW` but rendered on the real clock, so
the 0-hearts case depended on how much refill time had passed since `NOW`.

## What was fixed
`beforeEach` freezes `Date` at `NOW` (`vi.useFakeTimers({ toFake: ["Date"] })` +
`vi.setSystemTime(NOW)`). Timers stay real so `userEvent` still works.

## Acceptance criteria
1. The Practice tests freeze `Date` at `NOW`, and only `Date` is faked.
2. The 0-hearts case gives the same result whatever day the suite runs.
3. No production code changed.
