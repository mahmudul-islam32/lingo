# GAM-016: Topics screen "Life in Germany" with each lesson's path state
**Owner:** dev-gamification (criteria 1–15, 17–20) · dev-platform (criterion 16: the
`/topics` route file and the Practice tab highlight) · **Priority:** P1 · **Depends on:**
CTO-023, GAM-011, GAM-012; CON-005 for the real data (tests use the CTO-023 fixture) ·
**Milestone:** v0.5.6 Life in Germany topics · **Decisions:** PD-064, PD-071 #5, PD-086

## User story
As a newcomer to Germany, I want to browse everyday topics and see which of their lessons I've
done, which I can play now and which are still locked, so that I can practise what I need
without losing my place on the path (US-TP-01, US-TP-02, US-TP-03).

## Where it goes (PD-086)
A **"Life in Germany" card on the Practice tab**, below the Review card and above the list of
finished lessons, opens a new screen **`/topics`**. No new tab (the nav stays Learn / Practice
/ Leagues / Profile) and no section inside the Learn path, which auto-scrolls to the frontier.

## Acceptance criteria
### Entry
1. On Practice, when the active course has at least one topic, a card shows the title "Life in
   Germany", the line "Lessons for everyday situations" and the number of topics ("7 topics").
   The whole card is one link to `/topics` with the accessible name "Life in Germany, 7 topics".
2. When the active course has no topics (Einbürgerungstest, telc B1, en-es), the card is not
   rendered and Practice is otherwise unchanged (existing Practice tests pass unchanged).

### Topics screen
3. `/topics` shows a heading "Life in Germany" (h1), a back button "Back" to `/practice`, the
   line "Lessons for everyday situations. Locked lessons open as you move along your path.",
   and one row per topic in the data's order.
4. Each topic row is a disclosure button (`aria-expanded`, `aria-controls`) showing the title,
   the description and "<done> of <total> done". All topics start collapsed; Enter or Space
   toggles; several topics may be open at once.
5. An open topic lists its lessons in the data's order. Each lesson row shows the lesson title,
   a level and unit label (e.g. "A1 · Unit 11") and its state as an icon **and** a text label:
   **Done** (`completed`), **Up next** (the lesson Learn marks as up next: the frontier, the
   first `available` lesson at or after the start level), **Open** (any other `available`
   lesson, e.g. one of a level before the start level, PD-064) or **Locked** (`locked`).
6. **Same state as the path:** the state of every lesson is taken from `computePathNodes` with
   the same course, completed lesson ids and `settings.startLevel` as Learn uses, and "Up next"
   from the same frontier Learn shows (no second unlock rule). A unit test checks that for 3 fixture progress states (nothing
   done; start level A2; mid-A1 with 7 done) every topic lesson's state equals its path node's
   state.
7. Done, Up next and Open rows are links to `/lesson/<lessonId>`, the same URL the path uses,
   so the lesson route's rules decide lesson or free practice (PD-065) exactly as from the path.
8. **Locked lessons stay locked (PD-064):** a Locked row is not a link and not focusable, has no
   tap action, and reads "<title>, A2 · Unit 12, locked". Opening `/lesson/<id>` of a locked
   lesson by URL still redirects to Learn (existing behaviour, re-checked in the e2e).
9. "<done> of <total>" counts only completed lessons (review results never complete a lesson,
   ADR-019); a lesson listed in 2 topics counts in both.
10. A lesson id in the data that isn't in the loaded course manifest is left out silently and
    the total shrinks (defensive; the CTO-023 content test prevents it).
11. Changing the start level in Profile or finishing a lesson updates the states and counts the
    next time `/topics` is shown, without a reload.

### States
12. **Loading:** skeleton rows for the topics (no layout jump when they load).
13. **Error** (course or topics can't be read): Lumi, "We couldn't load the topics.", "Try
    again" (primary, refetches) and "Back" (to `/practice`).
14. **Empty** (`/topics` opened by URL on a course without topics): "There are no topics for
    this course yet." with "Back to Practice". No error is logged.
15. **Offline:** the screen works offline like Learn (bundled data); no offline message is
    shown on it.

### Route (dev-platform)
16. `src/app/topics/page.tsx` mounts the screen from `@/features/path` (or wherever GAM-016
    exports it); the bottom nav shows **Practice** as the active tab (`aria-current="page"`) on
    `/topics`. Nothing else in `src/app` changes.

### Quality
17. At 375 × 667: no horizontal scroll; titles truncate with an ellipsis only after 2 lines;
    every link and disclosure button is at least 48 px high; the bottom nav doesn't cover the
    last lesson row of the last open topic.
18. Keyboard only: Tab reaches Back, every topic button and every playable lesson link in
    order; focus is visible; the state is never shown by colour alone (icon + text); no
    serious or critical axe violations in collapsed, expanded, loading, error and empty
    states; AA contrast.
19. Unit / RTL tests: the pure view-model function (counts, states, dropped ids, order), the
    Practice card (shown / hidden), disclosure behaviour, link vs. locked rows, and the three
    states. e2e (Playwright, 375 px, keyboard only): Practice → Life in Germany → open "At the
    doctor's" → a Locked row has no link → open an Up next lesson → finish it → back on
    `/topics` the count went up by 1.
20. `npm run typecheck`, `lint`, `test`, `build` and the existing e2e pass.

## Out of scope
- "Start here" or any unlock from the Topics screen (use the path's level header, PD-064)
- Returning to `/topics` after a lesson automatically (the lesson flow ends as today; the e2e
  navigates back). Candidate P2 follow-up if analytics show topic use
- Topic search, filters, icons or pictures
- A topic section in Learn or a fifth tab
- Public topic landing pages (v1.0.0, PD-071)

## UX notes
- **Practice card:** same Card style as the Review card, a short line and a chevron.
- **Topic row:** title (Bricolage, bold), description (DM Sans, muted), "3 of 7 done" right
  aligned on wide screens and under the description at 375 px; a chevron that rotates when
  open (no rotation with `prefers-reduced-motion`).
- **Lesson row:** state icon left (check = Done, play = Up next, open circle = Open, lock =
  Locked), title, "A1 · Unit 11" muted; Locked rows are muted but keep AA contrast.
- **Loading / error / empty / success:** criteria 12–14; success = the list.
