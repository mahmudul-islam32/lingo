# GAM-002: XP calculation (`calculateXp`)
**Owner:** dev-gamification · **Priority:** P0 · **Depends on:** CTO-002 · **Milestone:** v0.2.0

## User story
As a learner, I want to earn XP for each lesson I finish, with a bonus for a perfect
lesson, so that my effort and accuracy are rewarded (US-GAM-04, US-GAM-05).

## Acceptance criteria
1. A pure function `calculateXp(summary, config)` in `/src/features/gamification` returns a
   breakdown `{ base, bonus, total }` (shape per contracts if defined there).
2. A completed lesson earns `base` = the configured lesson XP (default 10, PD-003).
3. A completed lesson with 0 mistakes and at least 1 counted exercise also earns `bonus` =
   the configured perfect bonus (default 5). `total = base + bonus`.
4. A lesson that was not completed (quit, or ended by running out of hearts in v0.3.0)
   earns 0 for all fields.
5. Skipped exercises (PD-007) don't count as mistakes and don't block the perfect bonus.
6. Replaying an already completed lesson earns the same XP as the first time (PD-008).
7. The function reads all values from the config argument (from contracts/config). It
   contains no XP number literals; a test with a custom config (e.g. 12 / 3) proves it.
8. It is exported from the gamification feature's public entry point so the lessons
   feature can import it.
9. Unit tests cover: perfect lesson (15), lesson with mistakes (10), not completed (0),
   only skipped exercises besides correct ones (15), custom config, replay. Branch coverage
   of the module is 100 %.

## Out of scope
- Storing XP totals and today's XP (GAM-003, v0.3.0)
- XP boosts, combos or time bonuses (not planned)
- Daily goal progress (GAM-006)

## UX notes
No UI. The results screen (LES-008) shows the breakdown.

## Parallel work
Contracts only. Can be built at the same time as GAM-001 and all LES tickets.
