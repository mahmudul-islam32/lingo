# GAM-010: Skill path with CEFR levels and many units
**Owner:** dev-gamification · **Priority:** P0 · **Depends on:** CTO-008, GAM-008 ·
**Milestone:** v0.3.1 · **Decisions:** PD-030, PD-036

## User story
As a German learner, I want my path grouped into CEFR levels and units, with my current
level open and later levels marked "Coming soon", so that I can see where I am on the way
from A1 to C1 without scrolling through hundreds of lessons.

## Context
GAM-008's path shows one unit header ("N of 5 lessons completed") and numbers lessons across
the course. German A1 alone has 12 units and 60 lessons, and the full course has five levels
(curriculum §2). The current path can't show level headers.

## Acceptance criteria
### Rules
1. `computePathNodes` (or a new pure helper next to it) works on the CTO-008 level layer:
   unlock order runs A1 unit 1 lesson 1 → … → the last lesson of the highest level with
   content. Finishing the last lesson of a unit makes the next unit's lesson 1 available.
   Finishing the last lesson of a level does the same for the next level's first lesson.
2. A pure helper returns, per level and per unit, `completed` and `total` lesson counts and a
   level state: `completed`, `current` (contains the available lesson), `locked`, or
   `coming_soon` (no units). 100 % branch coverage, including a level with no units and a
   course where every lesson is completed.

### Screen
3. The path shows a **level section** per level in CEFR order. Each has a header (`<h2>`) with
   the level title (e.g. "A1 · Beginner") and "N of M lessons completed", or "Coming soon"
   for a level with no units.
4. Inside a level, each unit has a header (`<h3>`) with "Unit N" (numbered within the level),
   the unit title and "N of 5 lessons completed" (count from the data, not a constant).
5. Lessons are numbered within their unit. Accessible names: "Unit 3, Lesson 2: <title>,
   completed" / ", up next" / ", locked". The locked toast says "Finish Unit 2, Lesson 4 to
   unlock this one." (the available lesson).
6. On open, **only the current level is expanded**. Completed and locked levels are
   collapsed behind a header button with `aria-expanded`. The learner can expand or collapse
   any level with content. "Coming soon" levels have no button and no nodes.
7. Collapsed levels render **no lesson nodes** in the DOM. With a fixture of 5 levels × 18
   units × 5 lessons, the initial render contains only the current level's nodes (RTL test).
8. The available node scrolls into view on open (GAM-008 criterion 11 kept, including
   reduced motion).
9. When the learner finishes the last lesson of a level, returning to Learn shows that
   level as completed and collapsed, and the next level expanded with its first lesson
   available, without a reload.
10. Every GAM-008 node rule still holds: states shown by icon + text, the 0-hearts gate and
    dialog, the locked toast, loading skeleton, course error with "Try again", results-error
    fallback (first lesson available), empty unit text.
11. The Spanish course (single level or no level data, per CTO-008) still renders correctly
    (RTL with the `en-es` fixture).
12. At 375 × 667: level and unit headers wrap without horizontal scrolling; tap targets at
    least 48 px; the last node isn't hidden by the bottom navigation.
13. No colour literals; level and unit headers use tokens with AA contrast in both themes. No
    serious or critical axe violations with a level expanded and collapsed.
14. RTL tests cover: level states and headers, expand/collapse with keyboard (Enter and
    Space), "Coming soon", cross-unit and cross-level unlocking, lesson numbering in names and
    in the toast, the large-fixture DOM check.

## Out of scope
- Level checkpoint node types, badges and "you completed A1" celebration (Phase 2)
- "Jump ahead" / placement tests (Phase 2)
- Unit cover art or per-unit colours
- Animations between levels

## UX notes
- **Layout:** level header card (indigo, level title, progress, chevron button), then unit
  header cards and nodes as in GAM-008. Collapsed levels are one compact row.
- **Coming soon:** muted row "B1 · Intermediate · Coming soon" with Lumi idle (sm) only on
  the first "Coming soon" level.
- **Loading / error / empty / 0 hearts:** as GAM-008.
- **Success:** tapping an available node opens the lesson.

## Technical notes
_(cto)_

- **Contracts:** `course.levels` (`{ level, title, description? }`), `unit.level`,
  `groupUnitsByLevel(course)` (levels with their units, empty → "Coming soon") and
  `flattenCourseLessons(course)` (unlock order) from `@/contracts`. Units are already grouped
  by level in CEFR order (schema rule), so today's flat unlock order in `computePathNodes` is
  correct; build the level/unit summary as a new pure helper in `src/features/path/rules/`.
- **Courses without levels (AC 11):** `course.levels` undefined → render one implicit section
  without a level header (en-es).
- **Fixture:** `src/lib/content/__fixtures__/german-fixture-course.ts` (A1 2 × 2, A2 empty);
  generate the 5 × 18 × 5 perf fixture in the test file and parse it with `CourseSchema`
  (`courseMaxUnits` is 150, so 90 units are valid).
- **Performance:** collapsed levels render no nodes; don't call `computePathNodes` per level,
  compute once and slice.
- **Tests:** 100 % branch coverage on the new helper; RTL for expand/collapse with keyboard.
