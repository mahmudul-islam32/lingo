# PLT-018: Onboarding "I already have an account"
**Owner:** dev-platform · **Priority:** P1 · **Depends on:** PLT-010, PLT-013, PLT-015 ·
**Milestone:** v0.6.0 Accounts and sync, part A (local Supabase) · **Decisions:** PD-011 (now
lifted), PD-087

## User story
As a returning learner on a new device, I want to log in from the first screen and skip
onboarding so that I'm back on my path in seconds (US-AC-01, US-AC-03).

## Acceptance criteria
1. With accounts enabled, onboarding's welcome step shows an indigo text link "I already have an
   account" under the primary button (PLT-026 criterion 4 style). With accounts disabled it is
   not rendered (PD-011 still applies to those builds).
2. The link opens `/log-in?from=onboarding` (email, and Google when its flag is on). Back returns
   to the welcome step.
3. After log-in the device's guest has no lesson results, so nothing is migrated (PLT-013
   criterion 4); the pull runs with "Loading your progress…" (`role="status"`) and Lumi.
4. **Account with settings:** onboarding is skipped and Learn opens on the account's course, path
   frontier and start level; Profile shows the account's stats.
5. **Account without settings** (signed up but never onboarded): onboarding continues at the
   course step; the choices are saved as the account's settings and synced.
6. **Pull fails or times out (10 s):** "We couldn't load your progress. Check your connection and
   try again." with "Try again"; the learner never lands on an empty Learn path that looks like
   a new account.
7. e2e (`accounts` project, two contexts): A finishes 2 lessons; fresh context B → welcome → "I
   already have an account" → log in → Learn shows the 2 lessons done without any onboarding
   step.
8. At 375 × 667 the link is a 48 px target and visible without scrolling on the welcome step;
   keyboard reachable after the primary button; no serious or critical axe violations.
   `npm run typecheck`, `lint`, `test`, `build` pass.

## Out of scope
- Sign up from onboarding (guests sign up after their first lesson, PLT-013, to keep time to
  the first lesson short, PRD G1)

## UX notes
- **Loading / error / success:** criteria 3, 6, 4. **Empty:** criterion 5.
