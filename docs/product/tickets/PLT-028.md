# PLT-028: Profile goal date and results row use the active course's plan; switch-course e2e
**Owner:** dev-platform · **Priority:** P1 · **Depends on:** CTO-018, GAM-014, FIX-014 ·
**Milestone:** v0.5.5 (per-course goal plan, must merge before PLT-010 / PLT-014) ·
**Decisions:** PD-077, PD-078

## User story
As a learner who switches between German and telc B1 Exam Prep, I want the goal date in
Profile to be the one of the course I'm on, and removing it to remove only that one, so
that my plans for different courses never mix (US-GD-05).

## Acceptance criteria
Field names and the patch shape follow CTO-018 and its ADR. Copy, dialog and validation are
unchanged from PLT-027.

### Profile
1. The "Goal date" row shows the **active course's** plan ("Finish <level> by <date>") or
   "Not set". On a course without levels it is absent (FIX-014, unchanged).
2. The dialog preselects and previews with the active course's plan and course
   (`computeGoalPlan` on that course's lessons and start level).
3. **Save** sets only the active course's plan through the per-course settings patch
   (CTO-018 criterion 2). Other courses' plans are unchanged (RTL test reading settings
   after the save).
4. **"Remove goal date"** clears only the active course's plan; the toast "Goal date
   removed." and "Not set" as in PLT-027 criterion 6. Other courses' plans stay.
5. Saving or removing still never changes `dailyGoalXp`, and the save-failure state of
   PLT-027 criterion 8 still applies.

### Learn and the lesson route
6. Learn keeps mounting `GoalPlanCard` with `useGoalPlan({ courseId })` for the active
   course; "Use <n> XP a day" still changes only `dailyGoalXp`.
7. The lesson route passes the goal-plan status of **the lesson's course** to
   `ResultsScreen` (the "only for the active course" guard in `LessonScreen` is removed, as
   the plan now belongs to the course). A course without levels still gets no row.
8. Course switch in Profile → Course: no plan is created, changed or deleted by the switch
   (unit test on the switch's settings patch).

### Quality
9. Works offline and for guests; no network call is added.
10. RTL tests cover criteria 1–5 and 7 with two courses; existing PLT-027 and FIX-014 tests
    pass, with fixtures moved to the new shape.
11. Accessibility: unchanged from PLT-027 (labels, focus return, linked errors); no serious
    or critical axe violations on Profile with the dialog open on each course.
12. At 375 × 667 the row and the dialog fit as in PLT-027 criterion 17 on both courses.
13. e2e (Playwright, 375 px, keyboard only, fixed clock 2026-11-21): on German, set A2 by
    2027-03-12 → Learn shows "Goal: finish A2 by 12 Mar 2027". Switch to telc B1 in Profile
    → the row shows "Not set" and Learn shows the "Set a goal date" link. Set B1 by
    2027-06-30 on telc B1 → its card shows it. Switch back to German → German's A2 plan is
    shown on Learn and in Profile. Remove it → telc B1's plan is still there after switching
    again.
14. `npm run typecheck`, `lint`, `test`, `build` and the full e2e suite pass.

## Out of scope
- The hook (GAM-014); the contract, migration and Supabase column (CTO-018)
- Showing or editing other courses' plans from one course
- A date-only goal for courses without levels (PD-078 §5)
- Sync of plans to an account (v0.6.0)

## UX notes
- **Rule shown to learners (PD-078):** the goal date always belongs to the course you are on.
- **Row states per course:** "Not set" + "Set"; "Finish A2 by 12 Mar 2027" + "Change"; absent
  on courses without levels.
- **Switching:** no toast or warning about plans; the row and Learn simply show the new
  course's plan.
- **Loading / error:** as PLT-027 (row renders after settings load; errors inline in the
  dialog).
