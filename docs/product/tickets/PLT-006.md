# PLT-006: Offline indicator and `useOnlineStatus` hook
**Owner:** dev-platform · **Priority:** P1 · **Depends on:** PLT-001 · **Milestone:** v0.1.0

## User story
As a learner, I want to see when I'm offline so that I understand why some features are
unavailable (US-PLT-16).

## Acceptance criteria
1. A `useOnlineStatus()` hook in `/src/lib/offline` returns the current online state and
   updates on the browser `online` / `offline` events. Other features can import it.
2. When the browser goes offline, a banner "You're offline. Some features need a
   connection." appears within 2 seconds, with `role="status"`.
3. When the browser comes back online, the banner changes to "Back online" for 3 seconds
   and then disappears.
4. If the app is opened while already offline, the banner shows on first render.
5. The banner never covers the bottom navigation or a page's primary button. At 375 px it
   takes at most 2 lines of text.
6. The banner has a text label and an icon; the state isn't conveyed by colour alone, and
   text contrast is at least 4.5:1.
7. With `prefers-reduced-motion: reduce`, the banner appears and disappears without
   animation.
8. The banner is not shown on `/lesson/*` routes (lessons work offline; the learner should
   not be distracted). The hook still works there.
9. Unit tests cover the hook (initial state, offline event, online event). A Playwright test
   uses `context.setOffline(true/false)` and checks both banner texts.

## Out of scope
- Showing a count of pending results to sync (PLT-014)
- Disabling auth buttons while offline (PLT-010)

## UX notes
- **Offline:** thin banner directly under the top of the page content, indigo background,
  off-white text, cloud-off icon.
- **Back online (success):** same position, short confirmation, then gone.
- **Loading/empty/error:** not applicable.

## Implementation notes
_(dev-platform, 2026-11-07, branch `feature/plt-002-pwa-offline`, shipped with PLT-002)_

1. `src/lib/offline/use-online-status.ts`: `useOnlineStatus(): boolean` via `useSyncExternalStore` on `online`/`offline`, `getServerSnapshot` → `true`; exported from `@/lib/offline`.
2. `src/app/_shell/OfflineBanner.tsx`: an always-mounted `role="status"` live region; offline text "You're offline. Some features need a connection." shows as soon as the `offline` event fires (e2e asserts within 2 s).
3. Back online: "Back online" for `BACK_ONLINE_MS = 3000`, then empty; the timer is cleared on unmount and by a new offline event (fake-timer unit tests). Serwist's `reloadOnOnline` is off so the page doesn't reload on reconnect.
4. Opened offline: shown right after hydration (server snapshot is online). Unit test plus `pwa.spec.ts` (offline reload served by the service worker).
5. Rendered in normal flow above `<main>` in the `(tabs)` and `onboarding` layouts, never fixed, so it can't cover the nav or a primary button. At 375 px it's 2 lines max (`text-sm`, `max-w-md`), checked in `tests/e2e/offline-banner.spec.ts`.
6. Inline cloud-off / cloud-check SVG icons (original) plus text; `bg-surface-raised text-fg` (contrast tested by `tokens.test.ts`, well above 4.5:1 in both themes).
7. Only `motion-safe:animate-fade-in`; e2e with `reducedMotion: "reduce"` checks `animation-name: none`.
8. Not placed in any lesson layout, and `isBannerSuppressed()` hides it on `/lesson` and `/lesson/*` (unit-tested). The hook works everywhere.
9. Unit tests: `src/lib/offline/__tests__/use-online-status.test.ts` (initial state online/offline, offline event, online event, cleanup, SSR) and `src/app/_shell/__tests__/OfflineBanner.test.tsx`. Playwright: `tests/e2e/offline-banner.spec.ts` with `context.setOffline(true/false)` checking both texts.
