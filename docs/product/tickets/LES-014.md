# LES-014: German in the lesson player (de-DE speech fallback, long words, language tags)
**Owner:** dev-lessons · **Priority:** P0 · **Depends on:** CTO-008, LES-007 · **Milestone:**
v0.3.1 · **Decisions:** PD-033, PD-034, PD-037

## User story
As a German learner, I want German audio when a recording is missing, and long German words
that fit on my phone screen, so that every exercise is playable and readable.

## Acceptance criteria
1. The listen fallback (PD-007) uses the course **speech locale** from CTO-008: in `en-de`
   it chooses a `de-DE` voice, else any voice whose `lang` starts with `de`, else shows
   "Audio isn't available right now." with the skip (unchanged PD-007 rules). It never
   picks a Spanish or English voice for German. Unit tests with mocked voice lists for all
   three cases.
2. Spanish (`en-es`) keeps its current fallback behaviour (regression test).
3. Slow playback uses `CONTENT_RULES.slowPlaybackRate` (0.7×) for both files and speech
   synthesis in German (PD-014).
4. Word bank and listen tiles render their **authored case** (`Brot` stays capitalised,
   `ich` stays lower case). RTL test with a German fixture.
5. The feedback panel shows `answers[0]` exactly as authored (umlauts, `ß`, capitals) with
   `lang="de"`.
6. All learning-language text (MC options, tiles, match-pairs learning side, feedback
   answer) has `lang` from the course's `learningLanguage` (`de`); prompts keep the known
   language (PD-019). RTL test with the German fixture.
7. **Long words at 375 px:** a tile `Krankenversicherungskarte` (25 characters), an MC option
   of 80 characters and a match-pairs item of 40 characters stay inside the viewport with no
   horizontal scrolling. Long words wrap (CSS `hyphens: auto` with `lang="de"`, or
   `overflow-wrap`). Playwright or RTL layout check at 375 × 667.
8. Umlauts and `ß` render in the app font in normal and bold weights (visual check recorded
   in the PR with a screenshot of `Ä Ö Ü ä ö ü ß`).
9. No serious or critical axe violations on each exercise type with the German fixture.

## Out of scope

## Technical notes
_(cto)_

- **AC 1–2:** in `src/features/lessons/audio/use-audio-playback.ts` call
  `audio.speech.findVoice(speechLocale(lang))` (`speechLocale` from `@/contracts`). `pickVoice`
  already scores an exact tag first and falls back to any voice of the base language, so
  `de-DE` → any `de-*` → `null` (PD-007 skip message). Test: voices `[de-CH (default), de-DE]`
  with `lang "de"` → `de-DE`; `[de-AT]` → `de-AT`; none → skip; Spanish (`es`) unchanged.
- **AC 4–5:** checking is case-insensitive (PD-010/PD-033), so never lower-case tiles for
  display; render the tile text as authored. Tiles that differ only by case are the same token
  for checking.
- **AC 6:** `lang` attributes already come from `learningLanguage`/`knownLanguage` props;
  add tests with the German fixture.
- **AC 7:** long words: `overflow-wrap: anywhere` / `break-words` plus `hyphens: auto` with
  `lang="de"`; tiles max 40 characters (contract).
- **Fixture:** `src/lib/content/__fixtures__/german-fixture-course.ts` or local exercise
  fixtures in German.
