# FIX-002: Multiple-choice content uses the English-prompt / Spanish-options convention
**Owner:** pm · **Priority:** P0 · **Depends on:** CON-001, LES-004 · **Milestone:** v0.2.0 ·
**Raised by:** CON-001 PM acceptance (2026-11-08) · **Branch:** `fix/fix-002-mc-content-direction`

## User story
As a learner who uses a screen reader, I want every Spanish word read with a Spanish voice
and every English word with an English voice so that I hear the right pronunciation in
multiple-choice exercises (US-CON-03, accessibility principle in the PRD).

## Problem
LES-004 renders a multiple-choice prompt with `lang={knownLanguage}` ("en") and every
option with `lang={learningLanguage}` ("es"). The contract has no direction field, so this
is the agreed convention (LES-004 and CON-001 Technical notes). Seven CON-001 items reverse
it: a Spanish word in the prompt and English options. Those render English options as
`lang="es"`, the quoted Spanish word as `lang="en"`, and LES-003 shows the English correct
answer as `lang="es"`.

## Acceptance criteria
1. These seven exercises keep their ids and are rewritten to the form "Which one means
   '<English>'?" with 3–4 Spanish options. Suggested rewrites (the correct option is in
   bold):
   - `u1-l1-ex06`: 'thank you'. Options **Gracias**, Adiós, Buenas noches
   - `u1-l2-ex02`: 'I am'. Options Eres, ¿Y tú?, **Soy**
   - `u1-l3-ex11`: 'I want'. Options **Quiero**, Por favor, Gracias
   - `u1-l4-ex02`: 'eight'. Options Seis, Diez, Siete, **Ocho**
   - `u1-l4-ex11`: 'seven'. Options **Siete**, Seis, Nueve, Cuatro
   - `u1-l5-ex02`: 'here'. Options ¿Dónde está?, Gracias, **Aquí**
   - `u1-l5-ex11`: 'where is'. Options ¿Cómo estás?, **¿Dónde está?**, ¿De dónde eres?
2. After the change, every `multiple_choice` prompt in `content/courses/en-es/lessons/*.json`
   quotes only English text, and every option `text` is Spanish. The pm checks this file
   by file; the result goes in Review.
3. Every option in the rewritten items is a word or phrase taught in that lesson or an
   earlier one (CON-001 vocabulary appendix), and the correct option is the only right one.
4. No lesson has two multiple-choice exercises that ask for the same English word.
5. `u1-l2-ex07` reads exactly "Which one means 'where are you from'?" (standard wording,
   CON-001 UX notes).
6. Each lesson still meets CON-001 criterion 3 (at least 3 MC, at least 3 word bank with
   both directions, 1 match pairs with 5 pairs, at least 2 listen) and keeps 12 exercises.
7. `npm run test` passes, including `src/contracts/__tests__/content.test.ts` and
   `tests/integration/lesson-flow.test.tsx`, which plays `u1-l1-hello`.
8. In the lesson player, each rewritten exercise renders its prompt with `lang="en"` and
   all options with `lang="es"`. When one is answered wrong, the feedback panel shows the
   Spanish correct answer with `lang="es"`. The pm checks this in the browser DevTools or
   with the integration test.

## Out of scope
- Reverse-direction multiple choice (Spanish prompt, English options). This needs a
  `direction` field on `MultipleChoiceExercise` (contract request to the cto) plus a
  LES-004 change. Phase 2 (PD-019).
- Audio files and the audio path layout (cto TTS pipeline).
- Any other content change. Exercise ids stay stable (CON-001 criterion 13).

## UX notes
- No new screens or states. Learners see a Spanish option list on these seven exercises
  instead of an English one. Recognition from Spanish to English is still practised by the
  `to_known` word banks and the match-pairs exercises.
- Loading, empty and error states: not applicable (content only).
