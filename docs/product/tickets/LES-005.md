# LES-005: Translate exercise (word bank)
**Owner:** dev-lessons · **Priority:** P0 · **Depends on:** CTO-002 (and the props interface in LES-002 Technical notes) · **Milestone:** v0.2.0

## User story
As a learner, I want to build a translation from a bank of word tiles so that I can
practise sentence structure without typing (US-LES-04).

## Acceptance criteria
1. Shows the instruction ("Translate this sentence"), the source sentence, an answer line
   and a word bank with the tiles from the content (answer words plus distractors),
   shuffled.
2. Works in both directions from the content: Spanish → English and English → Spanish.
   Each tile and the source sentence carry the correct `lang` attribute (`es` or `en`).
3. Tapping a bank tile moves it to the end of the answer line. Its place in the bank stays
   as an empty placeholder of the same size, so the bank doesn't shift.
4. Tapping a tile in the answer line returns it to its original place in the bank.
5. Repeated words work: two tiles with the same text are independent.
6. The component reports "answer ready" when at least one tile is in the answer line, and
   reports the ordered list of tile texts as the answer.
7. Keyboard: every tile is a button in tab order; Enter or Space moves it. When focus is on
   the answer line, Backspace removes the last tile back to the bank.
8. Screen readers: bank tiles are labelled "Add <word>", answer tiles "Remove <word>". The
   answer line is labelled "Your answer" and its current text is announced after each
   change.
9. When disabled (after "Check"), tiles can't be moved.
10. At 375 px: the answer line wraps onto as many lines as needed, tiles are at least
    44 px tall, and a bank of up to 12 tiles fits without horizontal scrolling.
11. With `prefers-reduced-motion: reduce`, tiles move without a flying animation;
    otherwise the animation is at most 300 ms.
12. The word-bank UI (answer line + bank) is a reusable component inside the lessons
    feature, so LES-007 can reuse it.
13. Unit tests cover: add, remove, duplicate words, keyboard (Enter, Space, Backspace),
    "answer ready" toggling, disabled state.

## Out of scope
- Typing the answer with a keyboard (Phase 2)
- Tap-to-hear on tiles (Phase 2)
- Drag and drop (tap only in MVP)

## UX notes
- Answer line: one or more ruled lines above the bank.
- Tiles: rounded, white with indigo border; placeholders are a light grey outline.
- **Empty:** answer line shows a faint "Tap the words" hint until the first tile is added.
- **Loading/error:** handled by the player.
- **Success:** standard feedback panel (LES-003).

- **Files:** reusable `src/features/lessons/exercises/word-bank/WordBank.tsx` (answer line + bank, props `{ tiles: string[]; tileLang: LanguageCode; disabled: boolean; onChange: (orderedTexts: string[]) => void; random?: () => number }`), its pure model `word-bank/word-bank-model.ts` (`{ slots: { id, text }[]; placed: number[] }` with `add(slotIndex)`, `remove(placedIndex)`, `removeLast()`; tiles are identified by **slot index**, never by text, so duplicates are independent), and `exercises/word-bank-translate/WordBankTranslateExercise.tsx` (instruction "Translate this sentence", prompt heading, `<WordBank>`). Register in `exercises/registry.ts`. Use `shuffle.ts` (see LES-004).
- **Behaviour:** `onAnswerChange(placed.length ? { type, tiles } : null)`. Placeholders keep the tile's measured size (`invisible` copy of the text keeps width; `aria-hidden`). Answer line: `role="group"` `aria-label="Your answer"`, focusable (`tabIndex={0}`) for Backspace; a polite `VisuallyHidden` live region announces the current answer text after each change.
- **Motion:** if you animate tile flight, use Framer Motion `LazyMotion` + `m` + `layoutId` with `useReducedMotion()` → no animation; keep ≤ 300 ms. Plain CSS without flight is acceptable.
- **UI (CTO-004):** tiles are `Button variant="secondary" size="md"` (≥ 44 px) or a local `Tile` styled with tokens; `cn()`.
- **Tests:** `word-bank-model.test.ts` (add/remove/removeLast/duplicates, pure) + RTL: labels "Add <word>"/"Remove <word>", Enter/Space/Backspace, answer-ready toggling, disabled blocks moves, live region text.
