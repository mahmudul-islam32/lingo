# CTO-009: Contract for a `cloze` (fill-the-gap) exercise type
**Owner:** cto · **Priority:** P1 · **Depends on:** CTO-008 · **Milestone:** v0.5.0
(non-blocking: A2 ships without it, PD-049) · **Decisions:** PD-019, PD-033, PD-049

**Status:** proposal by the pm. The cto decides the exact shape and records it as an ADR and
in `contract-requests.md`; the criteria below are the product needs.

## User story
As a German learner, I want to fill a gap in a German sentence by picking the right article,
ending or preposition, so that I can drill grammar choices (der / die / das, dem / den,
blauen / blaue, auf dem / auf den) quickly and without building the whole sentence.

## Acceptance criteria
1. `EXERCISE_TYPES` gains `cloze`, and `ExerciseSchema` accepts a strict `ClozeExercise`
   with: `id`; a learning-language `sentence` with **1 or 2** gap markers; one `gaps` entry
   per marker with **2–4** `options` (`id`, `text`) and a `correctOptionId`; a
   known-language `translation` (the English meaning shown under the sentence); optional
   `audio` of the full sentence.
2. Validation rejects: a marker count that differs from `gaps.length`; duplicate option ids
   or texts (case-insensitive) within a gap; a `correctOptionId` that isn't an option;
   option texts over 24 characters; a `sentence` over 80 characters after replacing the
   markers (CDS-13); `translation` over 80 characters.
3. **Gender choice is a cloze**: one gap at the start of a noun phrase with the options
   `der`, `die`, `das` (`___ Tisch`) is valid. No separate gender-choice type is added
   (PD-049).
4. An answer contract for cloze (one chosen option id per gap) exists, and the shared
   answer-check function reports `correct` only when **every** gap is right; the result says
   which gaps were wrong, so feedback can mark them.
5. `lang` rules are documented for the component: `sentence` and options in the course's
   `learningLanguage`, `translation` in `knownLanguage` (PD-019 is unchanged for MC).
6. Scoring follows PD-012 unchanged: one wrong check = 1 mistake and the exercise is
   re-queued; it costs 1 heart like any other exercise.
7. **Compatibility:** the cto documents what an older cached client does with a lesson that
   contains `cloze` (skip as unsupported, as for `speak` before LES-011, or a content
   version gate). Content may use `cloze` only after the release that contains LES-015.
8. Unit tests cover every rule in 1–4 with valid and invalid fixtures, including a German
   two-gap sentence (`Ich lege das Buch auf ___ Tisch.` / `Das ___ Kleid ist schön.`).
9. `curriculum-german.md` §5 / §6 can then point to the merged contract (pm updates the
   docs after merge).

## Out of scope
- The component (LES-015)
- Typed gaps and free text (Phase 2, PD-033 typed rules)
- More than 2 gaps, drag-and-drop, tiles shared between gaps

## UX notes
See LES-015. The contract must allow the sentence to be read as one German sentence by a
screen reader, with each gap announced as "blank, 1 of 2".
