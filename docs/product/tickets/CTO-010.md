## Order
1. CTO-012 first: it is the strongest recommendation for v1.1.0, and its `direction` field
   also unlocks reverse MC for content that doesn't use passages.
2. CTO-011 next (typed answers). Its checker is independent of the UI and can merge before
   LES-017.
3. CTO-014 with PLT-015, before the first B1 content merges (cache sizes grow with content).
4. CTO-013 last (v1.2.0).

Each contract ticket merges before its component ticket (as CTO-009 before LES-015). Content
may use a new type only from the release that contains its component (ADR-009 §5: content
is bundled with the build, so cached older clients never see a type they don't know).
