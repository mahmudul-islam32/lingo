# FIX-014: No goal-date card or link on Learn for courses without levels
**Owner:** dev-platform · **Priority:** P1 (blocks the v0.5.4 release) · **Depends on:**
PLT-027, GAM-013 · **Milestone:** v0.5.4 Goal date · **Raised by:** PM-ACC5 (PLT-027 AC 10
FAIL) · **Decisions:** PD-071 §1, PD-077

## User story
As a learner on a course without levels (Einbürgerungstest), I want Learn to show only what
works for my course so that I'm not sent to a setting that doesn't exist.

## Problem
On `einbuergerung-en-de` (available) and `en-es` (hidden), `useGoalPlan` returns `null`, so
`LearnScreen` renders GAM-013's "Have a date in mind? Set a goal date" link. The link opens
`/profile?edit=goal-date`, but there `GoalDateRow` renders nothing (no level to choose) and no
dialog opens. The learner taps the link and nothing happens.

## Acceptance criteria
1. When the active course has no level with lessons (today `einbuergerung-en-de` and `en-es`),
   Learn renders no goal-date UI at all: no "Set a goal date" link, no `goal-plan-empty`, no
   `goal-plan-card`. This holds with and without a saved `goalPlan`.
2. On `en-de` and `telc-b1-en-de`, Learn behaves as today: the link with no plan, the card
   with a plan (existing RTL tests and `goal-date.spec.ts` unchanged and green).
3. Opening `/profile?edit=goal-date` while the active course has no levels shows Profile
   normally, with no dialog, no error and no goal-date row. The `edit` query parameter is
   removed with history `replace` (no extra back step).
4. Switching to a course without levels doesn't change or delete the saved `goalPlan`.
   Switching back to `en-de` shows the same plan on Learn and in Profile.
5. The results screen of a lesson on a course without levels shows no goal-date row (already
   true; covered by a test).
6. Tests:
   - RTL: Learn on `en-es` and on `einbuergerung-en-de` (real course data or the same shape)
     has none of the elements in criterion 1; Learn on `en-de` still shows the link.
   - RTL: the Profile goal-date row is absent on a course without levels, and criterion 3.
   - e2e (375 px): onboard into Einbürgerungstest → Learn has no "Set a goal date" link.
7. `npm run typecheck`, `lint`, `test`, `build` and the full e2e suite pass.

## Out of scope
- A goal plan per course (CTO-018, PD-078)
- A date-only goal ("finish this course by …") for courses without levels (PD-078, later)
- Changes to `GoalPlanCard` or `useGoalPlan` (gamification). The guard belongs where Learn
  mounts the card. If the cleanest fix needs a hook change, write it in the PR and the cto
  routes it to dev-gamification.

## UX notes
- **Courses without levels:** Learn looks exactly as it did in v0.5.3 (top bar, Lumi and
  ring, caption, path).
- **Loading:** render nothing for the goal date until the course is known, as today, so no
  link flashes in and out on the exam course.
- The release notes line "courses without levels show no goal" becomes true with this fix.
