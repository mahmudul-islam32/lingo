# PLT-026: Redesign v2 for onboarding, app shell, 4-tab nav, Profile and platform states
**Owner:** dev-platform · **Priority:** P1 · **Depends on:** CTO-016 · **Milestone:** v0.5.3
Redesign · **Decisions:** PD-064, PD-066

## User story
As a learner, I want onboarding, navigation and my profile to look clear and consistent, and
my profile to show my real progress this week, so that I can see at a glance how I'm doing
and move between Learn, Practice, Leagues and Profile easily.

## Acceptance criteria
References: `docs/design/v2/screen-1.png` (onboarding) and `screen-8.png` (Profile), brief
tokens. **No behaviour change; existing tests keep passing** (copy may change only where noted;
tests that assert removed styles or the theme toggle are updated, not deleted).

### Onboarding (screen 1)
1. Welcome step: Polyglow wordmark with Lumi (not "parla" or its logo), large Bricolage
   headline, muted subline, canvas background, per screen 1.
2. Course step: "I WANT TO LEARN" eyebrow and one OptionCard per available course with a
   code badge ("DE" for German, German first) and a one-line subtitle; selected card has the
   indigo ring and check icon; only courses that exist are listed.
3. Level step (PD-064) and daily-goal step use the same OptionCard style and the same layout.
4. Each step has a full-width primary 3D Button at the bottom ("Continue" / existing label);
   any existing secondary link (e.g. sign-in) is shown as an indigo text link under it, and
   no link is added that leads nowhere.
5. Step order, saved values, Back behaviour and radiogroup keyboard behaviour are unchanged.

### App shell and nav (screens 2, 8)
6. A bottom nav with 4 tabs in this order: **Learn, Practice, Leagues, Profile**, each with an
   icon and label; the active tab is indigo, inactive tabs are muted grey.
7. Tabs route to `/` (or the existing Learn route), a Practice route, a Leagues route and
   `/profile`; the Practice and Leagues screen content is GAM-012, this ticket provides the
   routes and nav.
8. The nav is a `<nav aria-label="Main">`, the active tab has `aria-current="page"`, all tabs
   are reachable with Tab and activated with Enter; it is hidden inside a lesson as today.
9. Shell uses canvas background, light theme only; the theme toggle is removed (PD-066).

### Profile (screen 8)
10. Header: avatar circle with the learner's initials (indigo, white text; "?" or Lumi for a
    guest without a name), display name (or "Guest"), and "Learning German · Joined <Month
    YYYY>" from real data (the joined part is omitted when no date is stored).
11. Stat tiles (2 × 2): Day streak, Total XP, Lessons done, Start level, all from real data.
    No "Current league", "Words learned" or Achievements section (PD-066 §7).
12. "XP this week" card: 7 bars Mon–Sun for the current week from saved lesson results,
    today's bar in coral, days with 0 XP shown as an empty track, a dashed daily-goal line
    with the label "Goal <n> XP / day". A text alternative (e.g. visually hidden table or
    `aria-label` per bar "Wednesday, 40 XP") lists each day's XP.
13. With no results this week the chart shows empty bars and "No XP yet this week. Start a
    lesson to fill your chart." (not hidden).
14. Settings rows (daily goal, start level, other existing settings, sign-out if present):
    white card rows with label left, value + "Change" right; existing dialogs and their
    behaviour unchanged.

### Platform states
15. Offline banner, 404 page and install card are restyled with v2 tokens (Card, Button,
    Bricolage heading) with unchanged copy and behaviour.

### Quality
16. No serious or critical axe violations on onboarding steps, Profile, 404 and the shell;
    all text meets AA contrast.
17. At 375 × 667 every screen in this ticket fits without horizontal scroll; tap targets are
    at least 48 px; bottom nav does not cover the last content row.
18. Unit / RTL tests cover the nav (active tab, aria-current), the weekly chart (bars from
    results, goal line, empty state, text alternative) and the Profile stat tiles.
19. e2e (Playwright, 375 px, keyboard only): complete onboarding, move through all 4 tabs
    with the keyboard, and see Profile stats after finishing one lesson (today's bar > 0).
20. `npm run typecheck`, `lint`, `test`, `build` and existing e2e pass.

## Out of scope
- Practice list, Leagues screen, Learn path (GAM-012)
- Lesson player (LES-021)
- Achievements, league tier, words learned (not built)
- Dark mode (PD-066)

## UX notes
- **Loading:** Profile tiles and chart show skeletons; onboarding options show skeleton cards.
- **Empty:** chart empty state (criterion 13); guest profile shows "Guest" and the same stats.
- **Error:** if results can't be read, the chart shows "Couldn't load this week's XP." and the
  rest of Profile still renders.
- **Success:** values update after a lesson without a reload (as today).
