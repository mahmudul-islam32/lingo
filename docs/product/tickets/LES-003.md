# LES-003: Correct / incorrect feedback panel
**Owner:** dev-lessons · **Priority:** P0 · **Depends on:** LES-002, CTO-004 · **Milestone:** v0.2.0

## User story
As a learner, I want immediate, kind feedback after checking an answer, including the
right answer when I'm wrong, so that I learn from mistakes (US-LES-10, US-LES-11).

## Acceptance criteria
1. After "Check", a panel appears at the bottom of the screen, replacing the action bar.
2. **Correct state:** check icon and a heading picked at random from: "Nice work!",
   "That's right!", "Well done!".
3. **Incorrect state:** cross icon, heading "Not quite", then "Correct answer:" followed by
   the canonical answer from `checkAnswer`. Spanish text is wrapped in `lang="es"`.
4. For listen exercises, the panel also shows the Spanish sentence that was played (in
   both states).
5. The state is shown by icon and text as well as colour. Text and icons in both states
   have at least 4.5:1 contrast (functional success/error tokens, not brand colours,
   PD-001).
6. The panel content is announced to screen readers when it appears (live region), e.g.
   "Not quite. Correct answer: Buenos días."
7. The panel's "Continue" button receives focus when the panel appears; Enter or Space
   continues.
8. While the panel is open, the exercise inputs are disabled and can't be changed.
9. A long answer (up to 120 characters) wraps; the panel is at most 50 % of the viewport
   height at 375 × 667 and scrolls inside if needed.
10. Feedback copy never blames the learner. No words like "wrong", "fail" or "bad" in
    headings.
11. Appear animation is at most 300 ms and is removed under `prefers-reduced-motion`.
12. Unit tests render both states, check the live-region text and the focus on
    "Continue".

## Out of scope
- Sound effects (LES-012)
- "Report a problem" with this answer (Phase 2)
- Explanations of why the answer is wrong (non-goal for MVP)
- Mascot reactions in the panel (Phase 2)

## UX notes
- **Correct:** soft success background, dark text, check icon, "Continue" button in the
  success colour.
- **Incorrect:** soft error background, dark text, cross icon, answer in bold, "Continue"
  in the error colour.
- **Loading/empty/error:** not applicable; the panel only exists after a check.

## Technical notes
_(cto, 2026-11-07)_

**Owner agent:** dev-lessons · **Branch:** `feature/les-003-feedback-panel`

- **Contracts:** `AnswerCheckResult` (`outcome`, `correctAnswer`), `Exercise` (for listen: `exercise.answers[0]` is the sentence played), `LanguageCode` (wrap Spanish in `lang={learningLanguage}`).
- **Files:** `src/features/lessons/feedback/FeedbackPanel.tsx`, `src/features/lessons/feedback/headings.ts` (`pickCorrectHeading(random: () => number)` so tests are deterministic), wired into `ActionBar` of LES-002 (the panel replaces the action bar).
- **Props:** `{ result: AnswerCheckResult; exercise: Exercise; learningLanguage: LanguageCode; onContinue: () => void }`. Match pairs pass a synthetic `{ outcome: "correct", correctAnswer: null }` result.
- **UI (CTO-004):** colours are the functional tokens, never the brand ones: `bg-success-soft text-success-fg` + `Button variant="success"` and `bg-danger-soft text-danger-fg` + `Button variant="danger"`; icons `CheckIcon` / `CrossIcon` from `@/components/ui`. Max height `max-h-[50dvh] overflow-y-auto`.
- **Live region:** render a `VisuallyHidden` element with `role="status"` (polite) whose text is set when the panel mounts ("Not quite. Correct answer: Buenos días."). Focus "Continue" in an effect on mount (`ref.focus()`); Enter/Space work natively on the button. The player keeps `disabled` true while the panel is open (criterion 8).
- **Motion:** `motion-safe:animate-[slide-up_200ms_ease-out]` (keyframe in the CTO-004 tokens as `animate-slide-up`), none under reduced motion.
- **Tests:** RTL both states (headings set, "Correct answer:" + bold answer, `lang="es"`), live-region text, focus on "Continue", Enter calls `onContinue`, listen variant shows the sentence, heading copy never contains "wrong|fail|bad" (regex over all headings).
