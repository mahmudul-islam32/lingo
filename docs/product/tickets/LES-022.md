# LES-022: Results screen goal-date row
**Owner:** dev-lessons · **Priority:** P2 · **Depends on:** CTO-017, LES-021 · **Milestone:**
v0.5.4 Goal date · **Decisions:** PD-035, PD-071 §1

## User story
As a learner with a goal date, I want the results screen to tell me how many lessons are left
to my goal after each lesson so that I can see each lesson moving me closer (US-GD-03).

## Acceptance criteria
1. `ResultsScreen` accepts an optional prop with the CTO-017 `GoalPlanStatus` (computed after
   this lesson's result is saved; PLT-027 passes it). Without the prop, or with `null`, the
   screen is identical to today (existing tests and snapshots pass unchanged).
2. For `on-track`, `raise-goal` and `tight` it shows one row below the daily-goal row:
   "Goal: <level code> by <date>" and "<lessonsLeft> lessons left" (singular "1 lesson
   left"), date formatted as in GAM-013 criterion 9 ("12 Mar 2027").
3. For `reached` the row says "Goal reached: you've finished <level code>!" with the success
   colour and a check icon (icon `aria-hidden`; meaning is in the text).
4. For `date-passed` no row is shown (the Learn card handles it, GAM-013).
5. The row never shows "exam", "test", "pass", "behind", "late" or "failed" (whole words, case
   insensitive; RTL test over every status).
6. The row appears in the same order and reveal as the existing streak and daily-goal rows
   (LES-010 / LES-021); under `prefers-reduced-motion` it appears without animation.
7. Screen readers read the row as one text line in DOM order after the daily-goal row; no new
   focus stop is added; the primary "Continue" button stays the first focus target as today.
8. At 375 × 667 the results screen with all rows (XP, accuracy, time, streak, daily goal, goal
   date) still shows "Continue" without scrolling, or, if it does not fit, the content scrolls
   and "Continue" stays pinned as today; no truncated text; v2 tokens and AA contrast.
9. RTL tests cover criteria 1–7 for all five statuses and the absent prop; no serious or
   critical axe violations.

## Out of scope
- Computing the status and passing it from the route (GAM-013, PLT-027)
- A celebration animation or sound when the goal is reached
- Showing the row on the out-of-hearts screen or during practice-only changes

## UX notes
- **States:** absent (no plan, or `date-passed`); in progress (level, date, lessons left);
  reached (success style).
- Same row style as the daily-goal row (icon, label left, value right).
- Practice replays don't reduce `lessonsLeft`; the row then simply shows the same number.
