# PLT-004: Onboarding: choose course and daily goal
**Owner:** dev-platform · **Priority:** P0 · **Depends on:** PLT-001, PLT-003, GAM-001 (soft: use a placeholder image if not merged) · **Milestone:** v0.1.0

## User story
As a new visitor, I want to pick the language I want to learn and a daily goal so that I
get the right course and my habit target is set from the start (US-PLT-02, US-PLT-03).

## Acceptance criteria
1. `/onboarding` has three steps on one route: **Welcome**, **Course**, **Daily goal**. A
   text indicator shows "Step N of 3" on steps 2 and 3.
2. **Welcome:** shows Lumi (happy pose), the heading "Learn Spanish in five minutes a day"
   and one primary button "Get started". There is no "I already have an account" link yet
   (PD-011; added in PLT-018).
3. **Course:** lists the courses from the course data (one in MVP: "Spanish", subtitle
   "for English speakers") and a non-interactive line "More languages coming soon".
   "Continue" is disabled until a course is selected.
4. **Daily goal:** shows the goal options from contracts/config, by default 4 options:
   Casual 10 XP, Regular 20 XP, Serious 30 XP, Intense 50 XP, each with a hint
   ("About 1 lesson a day", "About 2 lessons a day", "About 3 lessons a day", "About 5
   lessons a day"). No option is preselected. The final button "Start learning" is disabled
   until one is chosen.
5. Course and goal options are radio groups (`role="radiogroup"` with an accessible name).
   Arrow keys move the selection; the selected option shows a check icon, not only a
   colour change.
6. Steps 2 and 3 have a "Back" button (`aria-label="Back"`) that returns to the previous
   step and keeps that step's selection.
7. On each step change, focus moves to the new step's `<h1>`.
8. "Start learning" saves the course and daily goal to the guest profile (PLT-003), sets
   onboarding complete, and navigates to `/`. (PLT-007 changes the target to Lesson 1.)
9. **Redirects:** while onboarding is not complete, opening `/` or `/profile` redirects to
   `/onboarding`. Once complete, opening `/onboarding` redirects to `/`.
10. Reloading during onboarding returns to the Welcome step with nothing saved.
11. **Error state:** if saving fails, an inline message "We couldn't save your choices.
    Please try again." appears with `role="alert"`, the learner stays on step 3 and the
    selection is kept.
12. **Empty state:** if no courses are available, the Course step shows "No courses are
    available right now." and a "Try again" button.
13. At 375 × 667, every option of the current step is visible without horizontal
    scrolling, options are at least 48 px tall, and the primary button is pinned to the
    bottom of the screen.
14. No serious or critical axe violations on any step.
15. A Playwright test (mobile project) completes onboarding as a new visitor with the
    keyboard only, lands on `/`, reloads, and stays on `/`.

## Out of scope
- Account creation or log-in during onboarding (v0.4.0)
- Placement test / "I know some Spanish" (Phase 2)
- Choosing a display name or avatar (PLT-016)
- Reminder time picker (Phase 2, with push reminders)

## UX notes
- **Welcome:** Lumi centred, large heading, short body "Short lessons, real progress.", one
  amber primary button at the bottom.
- **Course step:** one card per course with a flag-free label (we use language names, not
  flags). Selected card: indigo border plus check icon.
- **Daily goal step:** four stacked option rows; label left, XP right, hint below the label.
- **Loading:** skeleton cards while course data loads.
- **Error:** inline alert above the button; button stays enabled for retry.
- **Success:** goes straight to the next screen, no toast.
- Reduced motion: step changes without slide animation.
