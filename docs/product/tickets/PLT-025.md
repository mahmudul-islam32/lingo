# PLT-025: Start level in onboarding and Profile; lesson route with start level and practice
**Owner:** dev-platform · **Priority:** P1 · **Depends on:** CTO-015 (contract, ADR-013),
GAM-011 (path rule, start gate), LES-020 (practice flag), PLT-009 · **Milestone:** v0.5.2 ·
**Decisions:** PD-018, PD-064, PD-065

## User story
As a learner who already knows the basics, I want to pick where I start during onboarding
and change it later in my profile, so that the path begins at my level (US-SL-01, US-SL-03).

## Acceptance criteria
Names follow ADR-013 / CTO-015; the behaviour is what is tested.

### Onboarding step
1. After the language step and before the daily-goal step, onboarding shows the heading
   "Where do you want to start?" with one radio option per course level **that has
   content**, in course order, labelled "<code> · <title>" (today "A1 · Beginner" and
   "A2 · Elementary"). A level without lessons is not listed.
2. The first level (A1) is preselected; "Continue" is enabled at once.
3. A course with only one level with content skips the step (onboarding has the same steps
   as today).
4. "Back" returns to the language step and keeps the choice when coming forward again.
5. Finishing onboarding saves the choice as `settings.startLevel` for guests and signed-in
   learners; after onboarding, Learn shows the first lesson of that level as up next.
6. The options are a `radiogroup` labelled by the heading; arrow keys move the selection,
   Tab reaches "Continue", Enter / Space continues.

### Profile
7. Profile shows a row "Start level" with the current level ("A1 · Beginner" when not set)
   and a "Change" button (accessible name "Change start level").
8. "Change" opens a dialog (CTO-004 `Dialog`) with the same radio options and "Save" /
   "Cancel". Save stores `settings.startLevel`; Cancel and Escape change nothing; focus
   returns to "Change" on close.
9. When the chosen level is lower than the current one, the dialog shows "Lessons you
   haven't finished in earlier levels will lock again." before saving.
10. After Save, the Profile row and the Learn path (GAM-011) show the new level without a
    reload. If saving fails, the row keeps the old level and shows "We couldn't save your
    start level. Try again."
11. The setting syncs like the other settings (signed-in: across devices; offline: saved
    locally and synced later) and survives a reload.

### Lesson route
12. `/lesson/<id>` uses the GAM-011 path rule with the stored start level: an open
    (earlier-level, not completed) lesson plays; a locked lesson redirects to Learn
    (PD-018).
13. The route uses the GAM-011 start-gate function: a lesson completed before it starts
    opens `HeartsLessonPlayer` with the practice flag (LES-020) at any hearts; a
    not-completed lesson at 0 hearts shows the out-of-hearts screen.
14. A lesson completed for the first time in this session is not practice when it starts;
    starting it again afterwards is.

### Quality
15. Unit / RTL tests cover criteria 1–10 and 12–14 (routing with mocked path state), and
    there are no serious or critical axe violations on the onboarding step and the Profile
    dialog.
16. At 375 × 667 the onboarding step and the Profile dialog fit without horizontal scrolling,
    radio tap targets are at least 48 px, and contrast meets AA in both themes.
17. e2e (Playwright, 375 px, keyboard only): a new guest chooses "A2 · Elementary" in
    onboarding, lands on Learn with A2 L1 up next, opens an A1 lesson URL and it plays; then
    changes the start level to A1 in Profile and the A2 L1 URL redirects to Learn.
18. e2e: with 0 hearts, a completed lesson's URL opens the player with the "Practice" badge,
    and a not-completed lesson's URL shows "You're out of hearts".

## Out of scope
- The path rule, "Start here" and the path dialog (GAM-011)
- Hearts gains and practice behaviour inside the player (LES-020)
- A placement test (Phase 2 idea, PD-064)
- Changing the course language from Profile

## UX notes
- **Onboarding step:** Lumi (idle, sm) above the heading; each option is a card with the
  level code large and the title under it; selected card has the amber ring and a check
  icon (not colour alone).
- **Loading:** while the course levels load, two skeleton cards; "Continue" disabled.
- **Error:** if the levels can't be loaded, the step is skipped and the first level is used
  (no dead end).
- **Profile row:** label left, level and "Change" right; same layout as the daily-goal row.
- **Success:** after Save the dialog closes and the row shows the new level.
