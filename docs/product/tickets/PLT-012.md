# PLT-012: Password reset by email
**Owner:** dev-platform · **Priority:** P1 · **Depends on:** PLT-010, CTO-025 · **Milestone:**
v0.6.0 Accounts and sync, part A (local Supabase; mails are read from the local mail UI)

## User story
As a learner, I want to reset my password by email so that I can get back into my account
(US-PLT-08).

## Acceptance criteria
1. `/log-in` shows "Forgot password?" (PLT-010 criterion 6) linking to `/reset-password`.
2. `/reset-password` has an Email field and "Send reset link". After sending it always shows the
   same message: "If there's an account for <email>, we've sent a link to reset your password."
   It never reveals whether the account exists.
3. The link in the email opens `/auth/callback` (recovery), then `/reset-password/new` with New
   password and Confirm password fields (at least 8 characters; mismatch → "The passwords don't
   match.") and "Save new password".
4. After saving, the learner is signed in, sees "Your password has been changed." and goes to `/`;
   the old password no longer works.
5. An expired or already used link shows "This link has expired. Request a new one." with a
   "Request a new link" button to `/reset-password`.
6. Offline: both screens show the PLT-010 offline message and disable the button. Rate limit:
   "Too many attempts. Please wait a minute and try again."
7. e2e (`accounts` project, local Supabase): request a reset, read the email from the local mail
   UI, open the link, set a new password, log out, log in with the new password.
8. At 375 × 667 no horizontal scroll, 48 px targets, `autocomplete="new-password"` on both new
   fields, messages announced (`role="status"` / `role="alert"`); no serious or critical axe
   violations. `npm run typecheck`, `lint`, `test`, `build` pass.

## Out of scope
- Changing the password or email from Profile while signed in (later, with account settings)
- Magic-link sign-in

## UX notes
- **Loading:** "Sending…" / "Saving…" on the button. **Error:** criteria 3, 5, 6. **Success:**
  criteria 2 and 4. Same layout as PLT-010.
