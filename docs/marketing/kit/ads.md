# Short ad variants (6 drafts, v0.5.4)

**Last updated:** 2026-11-27 (MKT-002) · **Valid for:** v0.5.4 on `main`

**Status:** drafts. The owner creates the ad accounts, approves budgets and publishes. Run ads
only after the launch gate (`../launch-plan.md` §1). Each variant tests one message. Limits
follow common search-ad formats (headline ≤ 30 characters, description ≤ 90). No competitor
names in ad text or as bidded keywords; no exam brands; no exam-prep courses
(`../positioning.md` §5b); no legal claims; no "#1"/"best".

don't bid on exam-brand keywords even though people search them (`seo-keywords.md`). The ad
promises a plan, not a result.
