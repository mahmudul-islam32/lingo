# Short ad variants (5 drafts, v0.5.3)

**Status:** drafts. The owner creates the ad accounts, approves budgets and publishes. Run ads
only after the launch gate (`../launch-plan.md` §1). Each variant tests one message. Limits
follow common search-ad formats (headline ≤ 30 characters, description ≤ 90). No competitor
names in ad text or as bidded keywords; no exam brands; no legal claims; no "#1"/"best".
