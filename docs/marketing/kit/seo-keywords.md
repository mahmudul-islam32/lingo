# SEO keyword list (draft, v0.5.3)

**Status:** working list for landing pages (proposal #5) and store fields. No keyword tool was
available for this pass, so there are **no search-volume numbers here**. Priority is a marketing
judgement (est.) from intent and fit. Before investing in pages, the owner or cto can check
volumes in a free keyword planner (owner account; agents don't sign up).

**Rules:** keywords may describe demand, but page copy follows `../positioning.md` §5. Exam
brand names (Goethe, telc, ÖSD, TestDaF) are real searches but **must not appear in our page
copy** (PD-035), so they are listed only as "observed demand, not targeted". Never target
competitor brand names.
